# 以证据为界的三种复核

## evidence：证据核对

把论断拆为可核对的部分，与选定资源中的明确段落、表格位置或字段对应。区分直接观察、作者解释、引用他人结果和自己的推断。发现包含定位、原文或数值的简短摘录、对当前论断的影响、仍未核对什么。

引用格式正确不等于原文核实；“不显著”不能改写成“没有效应”；上传内容不自动获得可信来源。没有外部原始来源时标明“仅核对所提供文本”。合成示例只能证明流程行为。

## methods：研究设计与方法

按论断实际内容检查，不强加无关清单：

- 独立实验单位与嵌套层级：供体、样本、切片、细胞，以及技术重复与生物重复。
- 对照、配对、批次、混杂、缺失与选择偏倚；未提供则记录未知。
- 效应量、不确定性、多重检验与分析选择；未重算不宣称统计正确。
- 外推与因果：观察性关联、空间共定位或通信评分不能单独确认因果机制。
- 图表来源只在有原始数据、计算或可核对来源时判断；元数据声明匹配不等于图像核验。

提出具体后续验证，如“按供体聚合后检查方向与区间”，但未经适用授权不执行科学计算。把方法风险与已证实错误分开。

## challenge：异议与替代解释

先准确复述研究者质疑的意见，再检查其假设和所选反证。分别说明支持原意见、反对原意见的材料及无法区分的解释。异议缺少定位时问一个最小问题，不猜测。

原意见可能成立、需要缩小、证据不足或不适用；理由比标签更重要。Agent 新意见不能删除旧意见或代替研究者决定。建议修订时提供限定措辞，让研究者通过页面保存；保存后需要新快照审查。

## 发现质量

严重程度对应具体后果：`critical` 是可能破坏当前结论的关键问题；`warning` 是需核对的重要限制；`info` 是不阻断的说明。每项发现只处理一个可回应的问题，包含依据、推理、未知项与可执行下一步。不用多个 Agent 的一致意见充当独立科学复现。
