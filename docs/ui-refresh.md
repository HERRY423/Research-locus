## 页面与操作

- 白色页面、黑色文字与图标；黑色主按钮、选中标记、边框和文字区分状态，移除原来的绿色、米色与彩色风险标签。
- 左侧集中导航、新建、搜索和论断列表；中央显示当前论断与审查／证据标签页，右侧处理研究者判断。
- 顶部提供运行检查、添加文件、暂停／恢复；导出、刷新和边界说明放在更多菜单。
- 当前发现优先展示，过期发现折叠保留。合成示例标记和证据边界继续显示。
- 搜索支持 Ctrl+K 和中文组合输入；Esc 关闭菜单或导航，标签页支持方向键。
- 切换视图保留表单草稿和展开状态；修订草稿包含原论断基线，拒绝静默覆盖其他更新。
- 导入附件后直接打开证据页；以新增资源 ID 定位文件，避免重名材料选中旧附件。

仅改动工作台界面与相关浏览器操作。领域规则、已有审查档案和科学证据等级保持原有约束。ChatGPT 原生宿主验收仍待执行。
