# 独立首页：项目与会话回溯

2026-10-05。参照用户提供的独立插件页面与 Claude Science 首页截图，延续黑白配色。

插件全局入口打开无侧栏的完整首页：顶部搜索与新建项目，左栏项目列表，右栏最近保存的会话。选择项目可筛选该项目的会话并创建新会话；选择会话进入现有共审工作台，通过「项目首页」返回。工作台内的介入记录继续展示该会话的完整审查历史。

## 数据与入口

- 目录与会话保存在本机。默认 `.locus/catalog/catalog.json` 保存项目／会话索引，`.locus/catalog/sessions/<UUID>.json` 保存各新会话。
- 既有 `.locus/state.json` 直接作为 `legacy` 会话收录，不复制、不改写其历史，不把每个审查事件伪造成一个聊天会话。
- 新会话为空白状态，不预填合成科研结论；原合成示例继续标记为示例。
- 最近会话按最后保存时间排序。它们是 Research Locus 共审会话，未读取或导入 ChatGPT 的其他聊天记录。
- HTTP、SSE、MCP 操作和资源 URI 按会话显式绑定，不使用一个进程级的「当前会话」来路由所有客户端。
- 本地 `#session/<id>` 链接可恢复指定会话，`#project/<id>` 可恢复项目筛选；浏览器前进／后退可在首页与会话间导航。
- `locus.open` 使用独立 `ui://research-locus/home` 资源，优先 fullscreen；`locus.panel` 和文件入口保留原 workbench 资源。两种界面共用相同的持久化数据。

## 边界

新增项目和会话不改变科学证据等级，不启动模型或科研分析。研究者身份仍为声明身份。全局入口元数据与本地行为可被工程测试验证；ChatGPT 原生宿主中的实际独立页面展示仍需安装验收。
