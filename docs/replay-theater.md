# 回放剧场

侧栏新增「回放剧场」，与「介入记录」并列。进入后，左侧时间线选择步骤，右侧查看操作来源和修改前后内容。支持首步、上一步、播放／暂停、下一步、末步及进度条；每步播放 2 秒，到末步停止。方向键切步、空格播放，输入框和原生按钮保留自身键盘行为。

沿用黑白配色。减号和删除线表示修改前，加号和实线表示修改后；行号同时显示。窄屏时间线改为可横向滚动的步骤条，正文自动换行。回放页隐藏修改表单，返回当前共审后继续原工作。

## 记录范围

- 从本会话实际保存的事件与输入快照重建论断创建／修订、证据文本导入，以及审阅建议和研究者处理记录。
- 创建对象使用真实快照中的 ID；不把事件位置当快照位置，不把完整状态摘要误作输入快照摘要。历史快照按内容去重，支持 A → B → A 和无内容变化操作。
- 快照缺失、对应关系有歧义或历史断档时显示「仅摘要」，不以当前文本补写旧内容。规则检查事件没有保存当轮新增结果清单，故仅展示其操作摘要。
- 不重建未记录的模型内部过程，不采集宿主全部文件编辑。现有宿主文件写回没有持久化历史回执，因此不展示为已捕获的写回步骤；导入文件仅说明这些字节后来被纳入证据。
- 回放是只读视图，不回滚文件、不修改当前会话、不改变证据等级。离开剧场、切换会话、隐藏页面或收到新状态会停止播放。新记录不使游标自动跳到最后。

`src/replay.ts` 是无浏览器／服务器副作用的投影函数；原会话和事件结构未改变。逐行差异限制预览行数与字符数，大文本显示截断说明。完整记录仍可由共审页导出。
